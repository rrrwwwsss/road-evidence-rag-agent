# 执法与取证报告生成 Skill

## 目标

将案件数据库事实、知识库证据和用户指定范围整理成结构化 Markdown 报告草稿，保证统计、明细与引用可追溯。

## 触发意图

- `report_generation`
- 用户明确要求生成、整理或查询执法报告、取证报告、报表或文书草稿。

## 必需输入

- 报告时间、地区、单位、违法类型或案件范围中的至少一项有效限定；范围不清时保留用户原始表达。
- 数据库查询结果。
- 可引用的知识库案例证据。

## 执行流程

1. 调用 SQL Tool 获取报告范围的统计和明细。
2. SQL 失败立即停止，不生成带数字的报告。
3. 调用 RAG Tool 获取相关案件证据与来源。
4. RAG 失败立即停止，避免生成无来源事实。
5. 加载本包 `prompt.md`，将结构化数据和证据交给报告模型。
6. 检查报告是否包含摘要、事实与证据、分析、建议、不确定性和参考资料。

## 强制约束

- 调用顺序必须为 SQL → RAG → 报告生成。
- 禁止虚构案件编号、统计值、图片 URL、检测框、置信度和法规条款。
- 引用必须能够回溯到数据库记录或知识库来源。
- 个人敏感信息遵循最小必要原则。
- 报告始终标记为草稿并提示人工或执法部门复核。

## 输出

- Markdown 报告草稿。
- 数据库与知识库证据来源。
- 风险、不确定性和补证建议。
