# 图片违法与养护判定 Skill

## 目标

结合知识库判定标准、历史审核案例和用户上传图片，对道路施工、养护或疑似违法行为进行证据化评估。

## 触发意图

- `image_assessment`
- 用户上传图片并明确询问：是否违法、是否属于道路养护、如何认定、能否确认某类行为。

## 必需输入

- 真实上传的图片 ID。
- 明确的判定问题。
- 判定标准或相似案例证据；缺失时不得给确定性违法结论。

## 执行流程

1. 先调用 RAG Tool 获取相关判定标准和历史案例。
2. 将原始证据上下文完整交给 Vision Tool。
3. 视觉模型只基于可见要素和提供的证据进行对应分析。
4. 检查历史案例最终审核结果；若相似案例为 `is_committed=0`，不得沿用历史 AI 的违法判断。
5. 输出“确认违法、未确认违法、无法确定”之一，并列出证据和缺失项。

## 强制约束

- 调用顺序必须为 RAG → Vision。
- 不得跳过标准检索后仅凭视觉常识判定。
- “未确认违法”不等于“已确认合法”。
- 许可、审批、时间地点不可见时必须列为待核查证据。
- 最终法律结论需人工或执法部门复核。

## 输出

- 评估状态。
- 可见事实与证据对应。
- 不确定性和冲突证据。
- 补证清单及人工复核提示。
