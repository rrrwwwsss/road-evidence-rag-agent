# 图片相似案例检索 Skill

## 目标

从用户上传图片提取可观察的客观特征，并用这些特征检索相似历史案例。该能力只回答“哪些案例相似”，不回答当前图片“是否违法”。

## 触发意图

- `image_case_search`
- 用户上传图片，并询问类似案例、相似案例、历史案例或案例比对。
- 如果用户明确询问是否违法、是否属于某类行为或要求判定，应转到 `image_assessment`。

## 必需输入

- 至少一个真实上传的图片 ID。
- 用户希望比对的场景或案例类型，可为空。

## 执行流程

1. 调用 Vision Tool 的 `retrieval` 模式，只提取道路、车辆、机械、人员、物品、标志、空间关系和可见行为。
2. 禁止在视觉特征阶段输出违法、合法或未确认违法结论。
3. 将客观视觉描述与用户问题组合成检索词。
4. 调用 RAG Tool，并限定 `doc_type=case`。
5. 先区分“是否找到相似案例”和“是否找到最终审核已确认违法案例”。
6. 按案例编号列出事件类型、事件描述、地点、时间、图片/AI 描述、相似点、差异点、最终审核结果和来源。
7. 明确声明相似案例不能直接决定当前图片是否合法。

## 强制约束

- 调用顺序必须为 Vision 特征提取 → RAG 案例检索。
- 不检索标准文档替代案例结果。
- 不根据视觉模型输出推断许可、审批、人员身份或最终违法状态。
- 历史案例为 `is_committed=0` 时必须准确表述为“未确认违法”。

## 输出

- 图片客观特征摘要。
- 相似案例列表，以及其中是否存在最终审核已确认违法的案例。
- 每个案例对应的事件、地点、时间、描述、审核结果和图片地址。
- 相似点和差异点。
- 非违法认定声明。
