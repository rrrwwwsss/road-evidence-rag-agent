# 案件结构化查询 Skill

## 目标

将用户关于案件数量、明细、时间分布、所属单位、地点或违法类型的查询，转换为安全的只读数据库查询，并返回可核验结果。

## 触发意图

- `case_query`
- 典型表达：多少条、案件统计、哪个支队最多、查询案件明细、按月份汇总。

## 必需输入

- 用户原始问题。
- 可选实体：时间范围、支队或执法队、地点、违法类型、案件编号。

## 执行流程

1. 保留用户原始统计口径，不自行扩大时间或地区范围。
2. 调用只读 SQL Tool。
3. 校验工具是否成功、结果是否截断。
4. 用表格展示结果，同时保留实际 SQL 供内部核验。
5. 无结果时明确写“未查询到匹配案件”，不得解释为案件不存在。

## 强制约束

- 禁止执行写入、删除或结构变更 SQL。
- 禁止补造数据库中不存在的字段和统计值。
- 结果截断时必须提示用户缩小查询范围。
- 本 Skill 只处理数据库事实，不负责法规解释或图片判定。

## 输出

- 查询结果摘要。
- 结构化数据表。
- 查询 SQL 和截断提示。
- 数据库证据来源。
