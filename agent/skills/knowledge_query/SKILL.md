# 知识与案例检索 Skill

## 目标

从知识库检索判定标准、法规依据或历史案例，并生成带来源、可追溯、不过度推断的回答。

## 触发意图

- `knowledge_query`
- 典型表达：判定标准、法律依据、历史案例、典型案例、两类行为如何区分。

## 文档路由

- 标准、依据、法规、认定问题使用 `doc_type=standard`。
- 历史案例或案例编号问题使用 `doc_type=case`。
- 混合问题不限定文档类型。

## 执行流程

1. 根据用户问题确定文档类型。
2. 使用原始问题进行检索，避免长提示词污染召回。
3. 将本包的 `prompt.md` 仅用于检索后总结。
4. 回答中区分“资料明确记载”和“基于资料的概括”。
5. 没有资料时明确失败，不凭模型常识补充案件。

## 强制约束

- 每项关键事实必须能够回溯到知识库片段。
- 历史案例的 AI 输出不等于最终审核结论。
- `is_committed=0` 表示未确认违法，不能描述为已违法。
- 涉及执法结论时提示人工复核。

## 输出

- 结论摘要。
- 标准条目或案例列表。
- 来源与不确定性。
